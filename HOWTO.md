# Keyboard shortcuts

- `A`/`W`/`S`/`D` (or arrow keys): move left/up/down/right
- `Tab`: move to the next node; `Shift`+`Tab`: move to the previous
- `M`: toggle the sidebar
- `/`: open the sidebar and focus the search box
- `O`: toggle sound
- `+`/`-`: zoom in/out
- `R`: reset view to fit all nodes
