# AI assistant commit conventions (overrides global ~/.claude/CLAUDE.md for this repo)

This repo is not Linux kernel code, so the kernel coding-assistants policy
does not apply here. Do not add an `Assisted-by:` trailer.

Instead, end commit messages with:

```
Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>
```

Do not add a `Signed-off-by:` trailer — only the human author adds that.
